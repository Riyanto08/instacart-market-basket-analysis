# Dataset Information

## Source
- **Dataset:** Instacart Market Basket Analysis
- **Platform:** Kaggle
- **Link:** https://www.kaggle.com/datasets/psparks/instacart-market-basket-analysis

## Tables
| Table | Description |
|-------|-------------|
| `aisles` | 134 product aisles/categories |
| `departments` | 21 departments |
| `products` | 49,688 unique products |
| `orders` | 3.4 million orders from 206,209 users |
| `order_products_prior` | 32 million+ order-product records (prior orders) |
| `order_products_train` | Order-product records for training set |

## Notes
- Raw data files are not uploaded due to large file size
- Dataset can be downloaded directly from the Kaggle link above
- All tables were imported into PostgreSQL for analysis
